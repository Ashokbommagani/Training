7. Image Optimization

Image optimization means reducing image file size while maintaining acceptable quality.

  • Compress images.
  • Reduce unnecessary image dimensions.
  • Choose the correct image format.
  • Use responsive images.
  • Use lazy loading where appropriate.

Example: An optimized 300 KB image generally loads faster than an unnecessary 5 MB image.

8. Image Formats

JPEG / JPG

Suitable for photographs.

Example: student.jpg

PNG

Suitable for transparent images and logos.

Example: logo.png

SVG

Suitable for logos, icons and vector graphics.

Example: logo.svg

WebP

Modern format with efficient compression.

Example: course.webp

AVIF

Modern format designed for efficient compression.

Example: photo.avif
