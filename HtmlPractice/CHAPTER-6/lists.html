9. HTML Important Definitions

Ordered List (ol)
Displays items in a meaningful sequence.
Unordered List (ul)
Displays items using bullet points.
List Item (li)
Defines an individual list item.
Description List (dl)
Represents a collection of terms and descriptions.
Description Term (dt)
Defines the name or term.
Description Details (dd)
Provides the description of a term.
Nested List
A list placed inside another list item.
