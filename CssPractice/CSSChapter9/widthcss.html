CSS Width and Height

This card demonstrates width, height, max-width, min-width, max-height and min-height properties.

Resize the browser window and observe how the card adjusts its size while respecting the minimum and maximum dimensions.

The content can grow, and when it exceeds the maximum height, a scrollbar appears because overflow is set to auto.
